# Adidas Logo using OpenGL

This project draws the Adidas logo using OpenGL and GLUT in C++.

## Project Description

The program uses OpenGL polygons (QUADS) to create the Adidas logo shape.

## Technologies Used

- C++
- OpenGL
- GLUT

## Files

- `main.cpp` → Main source code
- `README.md` → Project documentation

## How to Compile and Run

### Linux

```bash
g++ main.cpp -lGL -lGLU -lglut -o adidas
./adidas
